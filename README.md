# 📊 Telecom Customer Churn Analysis

## 📌 Project Overview
This project analyzes telecom customer data to understand the main factors that contribute to customer churn.

The project covers the complete data analysis process, starting from understanding and cleaning the data to exploratory analysis, business insights, and dashboard creation.

## 🎯 Project Objectives
- Understand customer behavior and churn patterns.
- Identify the main factors associated with customer churn.
- Clean and prepare the dataset for analysis.
- Perform Exploratory Data Analysis (EDA).
- Answer important business questions.
- Create an interactive dashboard to present the results.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Excel
- Jupyter Notebook

## 📂 Project Structure

- `1) Proposal` – Project proposal and initial planning.
- `2) Dataset` – Raw telecom customer churn dataset.
- `3) Notebooks` – Data understanding, cleaning, preprocessing, EDA, and business analysis.
- `4) Dashboards` – Final dashboard and analyzed data.
- `5) Documentations` – Documentation for each stage of the project.

## 📈 Analysis Process

1. Business Understanding
2. Data Acquisition
3. Data Understanding
4. Data Quality Assessment

6. Exploratory Data Analysis (EDA)
7. Business Questions & Diagnostic Analysis
